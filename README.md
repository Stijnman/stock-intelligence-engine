**Stock Intelligence Engine**  
*Connect market narratives to your watchlist. Confirm with technicals. Explain every signal.*

**v2.1.0** — July 2026

An open-source Python tool that maps narrative themes from config.yaml to tickers, confirms with RSI(14), MA50/MA200, 52-week drawdown via yfinance, and outputs transparent `strong_buy` / `buy` / `hold` / `caution` signals with human-readable reasons. Now with X/Twitter viral scanner.
